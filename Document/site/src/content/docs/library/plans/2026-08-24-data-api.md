# Kế hoạch Data, Database và API tháng 8

## Mục tiêu

Tôi muốn luyện `EXPLAIN ANALYZE`, index, migration rollback, Redis cache-aside, rate limit và API envelope bằng feature HealthStride.

## Đã làm trong slice này

- Thêm index covering và migration có `upgrade/down`.
- Chạy PostgreSQL local, seed ít nhất 1.000 user/workout.
- Đo Home, history và leaderboard bằng `EXPLAIN ANALYZE`.
- Giữ cache leaderboard 60 giây, invalidation sau workout và lock chống stampede.
- Giữ rate limit GET 100/phút và POST 10/phút theo user.

## Chưa hoàn thành

Facebook/LINE OAuth và màn leaderboard Flutter sẽ là bước tiếp theo. Kết quả benchmark hiện tại chỉ là local với dữ liệu seed.

## Chạy lại

```bash
cd Backend
docker compose up -d
uv run alembic upgrade head
uv run python -m app.db.seed --users 1000
uv run python -m scripts.query_plans --output-dir ../Document/HealthStride/evidence/performance
```
